FART-O-IZER 6000™ - PLAN.txt
============================

Goal:
A fully client-side fart synthesizer web app using HTML, CSS, JS. Responsive, mobile-friendly, single-button UI with an expandable Advanced panel. All settings must serialize into a shareable URL. Hosted on GitHub Pages.

---------------------------------------
1. PROJECT STRUCTURE
---------------------------------------
/index.html
/style.css
/app.js
/assets/
    /img/ (button graphics, logo, etc.)
    /sounds/ (optional future use)
README.md
/docs/PLAN.txt (this file)

---------------------------------------
2. CORE FEATURES
---------------------------------------
- Single giant "FART" button on screen.
- Optional "Advanced" panel with sliders, toggles, and numeric inputs.
- Web Audio API synthesizer generating fart sounds:
  - Oscillator (low freq)
  - Noise generator
  - Envelope (attack/decay)
  - Filter (wet/dry)
  - LFO (wobble)
- All settings stored in a JS object.

---------------------------------------
3. RESPONSIVE UI PLAN
---------------------------------------
- Mobile-first layout.
- Centered main button.
- "Advanced" panel slides up from bottom on mobile, slides out on desktop.
- CSS grid or flexbox for settings layout.
- Minimal dependencies; pure CSS.

---------------------------------------
4. ADVANCED PANEL SETTINGS
---------------------------------------
(Initial set; expandable later)
- Oscillator frequency (bassiness)
- Noise amount (splatter)
- Filter cutoff (wetness)
- Envelope decay (length)
- LFO rate + depth (rumble)
- Master gain
- Randomize button (optional future)

---------------------------------------
5. SERIALIZATION & SHAREABLE URLS
---------------------------------------
- Settings object -> JSON -> base64 -> URL-safe encoding.
- Example:
  https://iamtew.github.io/fart-o-izer/?s=ENCODEDSTRING
- On load:
  - Check URL param "s"
  - Decode -> apply settings -> update UI
- Must avoid ugly long URLs:
  - Use compact keys (f, n, c, d, r, g)
  - Use base64url (replace +/ with -_)

8. APP.JS OUTLINE
---------------------------------------
- Initialize AudioContext
- Build fart synth engine
- UI bindings:
  - Main button -> playFart()
  - Sliders -> update settings object
  - Advanced toggle -> show/hide panel
- Serialization:
  - encodeSettings()
  - decodeSettings()
  - applySettings()
- On page load:
  - Check URL for settings
  - If present, decode + apply
